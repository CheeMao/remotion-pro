# StudioShow 模板规范

> 深色演播室 / 控制台风格横屏模板，适合复盘、汇报、数据讲解和策略内容。

## 风格概述

- 主气质：演播室、信息墙、控制台
- 画幅：横屏
- 材质：深色半透明面板、冷暖对撞高光、网格背景
- 节奏：开头抓主结论，中段给证据，结尾明确行动

## 适合内容

- 数据复盘
- 业务汇报
- 项目总结
- 策略拆解

## 设计规则

- 所有 layout 必须支持横屏下的主副区分
- 优先把证据放到侧栏或第二信息层
- 不新增无意义的系统文案或模板标签
- compare / stats / chart / timeline 要比竖屏模板更强调“证据感”
