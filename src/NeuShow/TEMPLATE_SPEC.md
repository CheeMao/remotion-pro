# NeuShow 模板规范

> 新拟态 (Neumorphism) 风格幻灯片模板，柔和立体设计，适用于工具产品介绍、设计趋势分享

## 模板概述

- **风格**: 新拟态 (Neumorphism / Soft UI)
- **尺寸**: 1080 x 1920 (9:16 竖版)
- **帧率**: 30 fps
- **单页时长**: 150 帧 (5秒)
- **转场**: 淡出切换

## 设计原理

新拟态通过双阴影实现凸起/凹陷效果：

```css
/* 凸起效果 */
box-shadow: 20px 20px 60px #bec3c9,  /* 深阴影 */
            -20px -20px 60px #ffffff; /* 浅阴影 */

/* 凹陷效果 */
box-shadow: inset 8px 8px 16px #bec3c9,
            inset -8px -8px 16px #ffffff;
```

## 内容配置规范

### 数据结构

```typescript
const slides = [
  {
    title: string;      // 主标题，建议 4-10 个字
    subtitle?: string;  // 副标题，建议 8-15 个字
    points?: string[];  // 要点列表，建议 3-5 条，每条 8-20 个字
  }
];
```

### 内容建议

| 字段 | 字数 | 建议 |
|------|------|------|
| title | 4-10字 | 核心主题，居中醒目 |
| subtitle | 8-15字 | 补充说明，可选 |
| points | 3-5条 | 每条 8-20字，关键要点 |

## 配色方案

### 背景色

```typescript
const bgColor = "#e8eef5";      // 浅灰蓝背景
const shadowDark = "#bec3c9";   // 深阴影色
const shadowLight = "#ffffff";  // 浅阴影色 (白色)
```

### 强调色轮换

```typescript
const accentColors = [
  "#6366f1",  // 靛蓝
  "#8b5cf6",  // 紫色
  "#ec4899",  // 粉色
  "#14b8a6",  // 青绿
  "#f97316",  // 橙色
];
```

每张幻灯片自动轮换强调色。

| 元素 | 动效 | 延迟 |
|------|------|------|
| 标题图标 | 缩放淡入 | 8帧 |

## 使用指南

### 创建新内容时

1. 修改 `src/NeuShow/index.tsx` 中的 `slides` 数组
2. 保持数据结构一致
3. 建议幻灯片数量 3-6 张

### 调整时长

```typescript
const SLIDE_DURATION = 150;  // 修改帧数
```

### 修改背景色

在 `NeuSlide.tsx` 中修改：

```typescript
const bgColor = "#e8eef5";      // 背景色
const shadowDark = "#bec3c9";   // 深阴影（比背景深）
const shadowLight = "#ffffff";  // 浅阴影（通常白色）
```

**注意**: 新拟态效果需要背景、深阴影、浅阴影三者协调，修改时保持色相关系。

### 渲染输出

```bash
npx remotion render NeuShow out/neu.mp4
```

## 注意事项

1. **配色协调**: 背景、深阴影、浅阴影需同色系，对比度适中
2. **强调色**: 用于标题图标和序号，不宜过多
3. **圆角统一**: 保持圆角一致（卡片40px，条目24px，按钮14px）
4. **可读性**: 浅色背景上文字使用深色，确保对比度
