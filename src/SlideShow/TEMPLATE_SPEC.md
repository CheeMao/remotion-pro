# SlideShow 模板规范

> 科技风知识卡片幻灯片模板，适用于抖音/视频号竖版短视频

## 模板概述

- **风格**: 赛博朋克科技风
- **尺寸**: 1080 x 1920 (9:16 竖版)
- **帧率**: 30 fps
- **单页时长**: 150 帧 (5秒)
- **转场**: 淡出切换

## 文件结构

```
src/SlideShow/
├── index.tsx    # 入口文件，配置幻灯片内容
└── Slide.tsx    # 单页组件，样式动效逻辑
```

## 内容配置规范

### 数据结构

```typescript
const slides = [
  {
    title: string;      // 主标题，建议 4-10 个字
    subtitle?: string;  // 副标题，建议 8-15 个字
    points?: string[];  // 要点列表，建议 3-5 条，每条 8-20 个字
  }
];
```

### 内容建议

| 字段 | 字数 | 建议 |
|------|------|------|
| title | 4-10字 | 核心观点，简洁有力 |
| subtitle | 8-15字 | 补充说明，可选 |
| points | 3-5条 | 每条 8-20字，关键信息 |

### 示例配置

```typescript
const slides = [
  {
    title: "Claude Code 是什么？",
    subtitle: "一款革命性的 AI 编程助手",
    points: [
      "命令行工具，在终端中运行",
      "理解整个代码库，智能编辑",
      "自然语言交互，无需记忆命令",
    ],
  },
  {
    title: "核心功能",
    subtitle: "强大且易用的开发工具",
    points: [
      "读取、编辑、创建文件",
      "运行命令和测试",
      "Git 操作自动化",
    ],
  },
  {
    title: "开始使用",
    subtitle: "三分钟快速上手",
    points: [],  // 空数组表示无要点，只显示标题
  },
];
```

## 动效说明

| 元素 | 动效 | 延迟 |
|------|------|------|
| 标题 | 弹性缩放 + 上移 | 8帧 |
| 副标题 | 上移淡入 | 18帧 |
| 分隔线 | 宽度展开 | 25帧 |
| 要点 | 左滑入场 | 40帧起，每个间隔15帧 |
| 整体 | 结尾淡出 | 135-149帧 |

## 使用指南

### 创建新内容时

1. 修改 `src/SlideShow/index.tsx` 中的 `slides` 数组
2. 保持每条幻灯片的数据结构一致
3. 建议幻灯片数量 4-8 张，总时长 20-40 秒

### 调整时长

```typescript
const SLIDE_DURATION = 150;  // 修改此值，单位：帧
// 150帧 = 5秒 @ 30fps
// 180帧 = 6秒
// 120帧 = 4秒
```

### 渲染输出

```bash
npx remotion render SlideShow out/slide.mp4
```

## 注意事项

1. **字数控制**: 标题过长会导致换行，影响美观
2. **要点数量**: 超过5条可能超出屏幕，建议控制在3-5条
3. **空要点**: `points: []` 时只显示标题和副标题，适合结尾页
4. **背景统一**: 所有幻灯片使用相同深色背景，通过彩色光效区分
