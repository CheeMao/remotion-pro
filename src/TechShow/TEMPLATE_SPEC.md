# TechShow 模板规范

> 科技感特效幻灯片模板，包含扫描线、数据流粒子、电路线条、全息框等丰富动效

## 模板概述

- **风格**: 赛博科技风 + 代码终端感
- **尺寸**: 1080 x 1920 (9:16 竖版)
- **帧率**: 30 fps
- **单页时长**: 150 帧 (5秒)
- **转场**: 淡出切换

## 动效特色

| 特效 | 说明 |
|------|------|
| **扫描线** | 横向光线从上到下扫描 |
| **数据流粒子** | 20个粒子持续流动 |
| **电路线条** | SVG 线条逐步绘制 |
| **全息框** | 四角装饰 + 故障抖动 |
| **终端文字** | 打字机效果 + 闪烁光标 |
| **数字计数器** | 跳动数字 + 随机故障色 |
| **进度条** | 发光填充动画 |

## 页面类型

### title - 标题页
- 终端提示文字（打字机效果）
- 主标题（带故障抖动效果）
- 状态指示器（READY/ONLINE/SECURE）

### stats - 数据页
- 终端标题
- 数字计数器（跳动 + 故障色）
- 多列布局

### list - 列表页
- 全息框包裹
- 序号方块
- 文字 + 描述

### progress - 进度页
- 终端标题
- 发光进度条
- 百分比显示

### compare - 对比页
- 左右对比框
- VS 分隔符
- 不同边框颜色

### quote - 引用页
- 全息框包裹
- `<QUOTE>` 标签
- 引用内容 + 作者

### cta - 行动号召页
- 终端提示
- 大标题
- 脉冲按钮

## 使用指南

修改 `src/TechShow/index.tsx` 中的 slides 数组：

```typescript
const slides = [
  {
    type: "title",
    data: {
      title: "标题文字",
      subtitle: "副标题",
    },
  },
  {
    type: "stats",
    data: {
      title: "数据标题",
      stats: [
        { value: 100, suffix: "%", label: "标签" },
      ],
    },
  },
  // ...其他类型
];
```

## 渲染输出

```bash
npx remotion render TechShow out/tech.mp4
```
