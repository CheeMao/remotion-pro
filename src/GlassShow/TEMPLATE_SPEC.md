# GlassShow 模板规范

> 毛玻璃风格幻灯片模板，现代简洁设计，适用于抖音/视频号竖版短视频

## 模板概述

- **风格**: 毛玻璃 (Glassmorphism) + 渐变
- **尺寸**: 1080 x 1920 (9:16 竖版)
- **帧率**: 30 fps
- **单页时长**: 150 帧 (5秒)
- **转场**: 淡出切换

## 文件结构

```
src/GlassShow/
├── index.tsx       # 入口文件，配置幻灯片内容
└── GlassSlide.tsx  # 单页组件，样式动效逻辑
```

## 内容配置规范

### 数据结构

```typescript
const slides = [
  {
    title: string;      // 主标题，建议 4-10 个字
    subtitle?: string;  // 副标题，建议 8-15 个字
    points?: string[];  // 要点列表，建议 3-6 条，每条 8-25 个字
  }
];
```

### 内容建议

| 字段 | 字数 | 建议 |
|------|------|------|
| title | 4-10字 | 核心主题，居中醒目 |
| subtitle | 8-15字 | 补充说明，可选 |
| points | 3-6条 | 每条 8-25字，关键要点 |

### 示例配置

```typescript
const slides = [
  {
```

## 视觉特性

### 毛玻璃卡片

- 固定高度: 900px (约屏幕 47%)
- 半透明背景: `rgba(255, 255, 255, 0.08)`
- 模糊效果: `backdrop-filter: blur(20px)`
- 圆角: 40px
- 边框: 1px 半透明白色

### 装饰元素

| 元素 | 说明 |
|------|------|
| 动态渐变背景 | conic-gradient 旋转 |
| 轨道圆点 | 8个彩色圆点环绕旋转 |
| 页码标签 | 右上角胶囊形状 |
| 底部指示器 | 圆点/横条进度条 |

## 动效说明

| 元素 | 动效 | 延迟 |
|------|------|------|
| 卡片 | 轻微浮动 (8px) | 持续 |
| 标题 | 上移 + 模糊到清晰 | 10帧 |
| 副标题 | 上移淡入 | 22帧 |
| 要点条目 | 左滑入场 | 40帧起，每个间隔15帧 |
| 整体 | 结尾淡出 | 135-149帧 |

## 使用指南

### 创建新内容时

1. 修改 `src/GlassShow/index.tsx` 中的 `slides` 数组
2. 保持数据结构一致
3. 建议幻灯片数量 3-6 张

### 调整时长

```typescript
const SLIDE_DURATION = 150;  // 修改帧数
// 150帧 = 5秒 @ 30fps
```

### 调整卡片高度

在 `GlassSlide.tsx` 中修改 `height: 900`:

```typescript
height: 900,   // 当前值
// height: 1000,  // 更高
// height: 800,   // 更矮
```

### 渲染输出

```bash
npx remotion render GlassShow out/glass.mp4
```

## 注意事项

1. **卡片高度固定**: 不同内容量不影响卡片大小
2. **要点数量**: 建议 3-6 条，过多会挤压空间
3. **配色协调**: 紫粉青橙四色交替，保持视觉平衡
4. **结尾页**: `points: []` 适合作为总结页或 CTA 页
