# EditorialShow 模板规范

> 轻杂志 / 版面叙事风格横屏模板，适合观点表达、案例拆解和内容型讲述。

## 风格概述

- 主气质：编辑感、留白、纸面、标题版式
- 画幅：横屏
- 材质：暖白纸面、轻玻璃面板、较克制的高光
- 节奏：标题先立意，中段拆观点，结尾有收束

## 适合内容

- 观点视频
- 案例拆解
- 品牌故事
- 内容型讲解

## 设计规则

- 横屏布局要保留明显留白，不能重新堆回竖屏密度
- hero / quote / cta 要有更强的版面感
- list / steps / timeline 以“阅读秩序”优先，不用伪系统标签强化风格
- 禁止加入模板解释文案和无信息价值的固定文字
